Trading Platforms Administrator (Junior/Middle)


            .NET developer take-home assignment
Careers
Description:
Develop a web application to get user coordinates by their IP address and to get a list of locations by the city name.
Development tools:
C#, ASP.NET Core
MS Visual Studio
HTML5, CSS3, JavaScript
Do not use DBMS
Architecture and source code requirements:
The web application must be designed and developed for the capacity of 10,000,000 unique users per day and 100,000,000 requests per day.
The client side should be implemented as a Single Page Application; it should be lightweight and written in JavaScript without using third-party frameworks for SPA.
The source code must have a uniform style and contain the necessary comments.
Neatness of the source code will be evaluated alongside the functionality of the application.
There is no minimum supported browser version requirement for the client code. You can use the features of the latest browser versions (Chrome, Firefox, Edge).
Platform: Windows 10 or Windows Server 2019.
The result must not contain *.exe or *.dll files.
Application technical description:
The database is stored in the geobase.dat file which is provides in the attached zip. The database will not change; it is read-only.
The database has a binary format. The file contains:

60 bytes - the header
int   version;       	// database version
sbyte name[32];          // database name/prefix
ulong timestamp;     	// database creation time
int   records;       	// the total number of records
uint  offset_ranges; 	// offset from the beginning of the file to the beginning of the list of records with geo data
uint  offset_cities; 	// offset from the beginning of the file to the beginning of the index sorted by city names
uint  offset_locations;  // offset from the beginning of the file to the beginning of the list of location records

12 bytes * Header.records (number of records) — the list of records with the information about the ranges of IP addresses sorted by ip_from and ip_to fields
uint ip_from;       	// beginning of the range of IP addresses
uint ip_to;         	// end of the range of IP addresses
uint location_index;    // index of the location record
96 bytes * Header.records (number of records) — the list of records with the information about locations with coordinates (longitude and latitude)
sbyte country[8];        // country name (random string with the "cou_" prefix)
sbyte region[12];        // region name (random string with the "reg_" prefix)
sbyte postal[12];        // postal code (random string with the "pos_" prefix)
sbyte city[24];          // city name (random string with the "cit_" prefix)
sbyte organization[32];  // organization name (random string with the "org_" prefix)
float latitude;          // latitude
float longitude;     	// longitude
4 bytes * Header.records (number of records) — the list of location indexes sorted by city name; each index is the address of the record in the file relative to Header.offset_locations
The whole database is loaded into memory when the application starts.
The database should be loaded into memory in one thread, without parallelization.
Database loading time should not exceed 30 ms (reading from SSD).
Implement fast (binary) search in the loaded database by the IP address and by the exact case sensitive match of the city name.
Two HTTP API methods must be implemented in the application:


GET /ip/location?ip=123.234.123.234
GET /city/locations?city=cit_Gbqw4
Server response to each request must be presented in the JSON format.


The client part must be implemented in the Single Page Application ideology
The page should consist of two parts: the left part with the screen switching menu and the right part where the selected screen is displayed.
The client part must implement two screens: search for geo data by IP and search for a list of locations by city name.
The geo data search screen contains: a field to input the IP address, a Search button and an area to output the result.
A click on Search send to the server the following request: GET /ip/location?ip=123.234.123.234
The processed server response is displayed in the result output area.
The locations search screen contains: city name input field, a Search button and an area to output the result.
A click on Search send to the server the following request: GET /city/locations?city=cit_Gbqw4
The processed server response is displayed in the result output area.
